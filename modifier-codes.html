Important modifier rules
  • Use a modifier only when the code descriptor, official CPT/HCPCS guidance, payer policy, and documentation support it.
  • Modifier 59 and XE/XP/XS/XU are not shortcuts to bypass NCCI edits. Check the specific PTP edit and its modifier indicator.
  • Some modifiers are restricted to professional claims, facility claims, specific code families, or specific payers.
  • This is a practical selected reference, not a complete licensed AMA CPT modifier list or a guarantee of coverage/payment.
  • Confirm current year policy, NCCI edits, MAC/LCD/NCD, and payer billing instructions before claim submission.
